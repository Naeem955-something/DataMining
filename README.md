# 🛒 Online Retail II Dataset

## 📌 Dataset Info

* **Name:** Online Retail II
* **Source:** Kaggle (Original: UCI Machine Learning Repository)
* **File:** `online_retail_II.xlsx`

## 📊 Description

Transactional data from a UK-based online retail store containing customer purchases, product details, quantities, prices, and timestamps. The dataset is real-world, large-scale, and noisy, making it suitable for data mining and machine learning applications.

## 🧾 Attributes

* 🧾 **Invoice** – Transaction ID
* 📦 **StockCode** – Product code
* 📝 **Description** – Product description
* 🔢 **Quantity** – Items purchased
* 📅 **InvoiceDate** – Date & time
* 💰 **Price** – Unit price
* 👤 **CustomerID** – Customer identifier
* 🌍 **Country** – Customer country

## 💡 Why This Dataset

* ⚠️ Missing values (data cleaning)
* 📉 Outliers (noise detection)
* 🔢 Numeric + categorical features
* 🛍️ Transactional structure (Apriori)
* 📊 Large dataset (clustering)

## ⚙️ Techniques Used

* 🧹 Data cleaning & outlier detection
* 📈 Regression (Linear, Multiple, Polynomial)
* 🧠 Classification (Logistic, Decision Tree, KNN, Naive Bayes)
* 🔍 Clustering (K-Means)
* 🔗 Association Rules (Apriori)
* 📊 Evaluation (Confusion Matrix, Precision, Recall, F1, ROC)

## 🎯 Usage

Educational and research purposes in **Data Mining**.
